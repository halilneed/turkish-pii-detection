Model version and processing / Model sürümü ve işleme
Original v02 weights: 28644718923ae38b0105c9f3d2be57312ad0ced3. ONNX dynamic uint8 quantization; deterministic generation; Transformers.js 4.3.0. Runs in a Web Worker using WebAssembly. The demo does not save inputs or outputs. Original benchmark scores have not been revalidated for this conversion. Model weights remain subject to Gemma Terms.
